# Batyr FIT

Браузерное приложение для тренировок: профиль и замеры тела, каталог упражнений по группам мышц (до 50 на группу, с фото техники и инструкцией), журнал тренировок с подходами, весом и повторами, история и личные рекорды по каждому упражнению.

Сервер и база данных не нужны: это статичный сайт, данные хранятся в `localStorage` браузера. В профиле есть резервная копия (скачать / загрузить JSON).

## Публикация на GitHub Pages
Workflow `.github/workflows/pages.yml` публикует сайт при каждом пуше в `main`.
Один раз включите: *Settings → Pages → Build and deployment → Source: GitHub Actions*.

## Локально
```
python3 -m http.server 8000
```
и откройте http://localhost:8000 (двойной клик по `index.html` не сработает — браузер не даст загрузить JSON).

## Структура
- `index.html` — разметка и стили
- `app.js` — логика: профиль, каталог, журнал
- `data/exercises.json` — 15 групп мышц, 536 упражнений
- `img/` — фото начального и конечного положения (сжатые до 480px)

## Источник упражнений
[free-exercise-db](https://github.com/yuhonas/free-exercise-db) — открытая база, лицензия Unlicense (public domain), см. `data/LICENSE-exercises.md`.
Порядок внутри группы: силовые базовые со штангой/гантелями → блоки, тренажёры, свой вес → вариации и упражнения, где мышца работает как вспомогательная. В группе «Шея» в базе всего 8 упражнений.
